# 🚀 Evaluación: Fundamentos de Git y Automatización (CI)

Este repositorio contiene la implementación de un flujo de trabajo profesional utilizando **GitFlow**, documentación estandarizada en **Markdown** y automatización de calidad mediante **GitHub Actions**.

## 📋 Descripción del Proyecto
El objetivo principal es demostrar el dominio de:
* **Gestión de Ramas:** Uso de `main`, `develop` y ramas `feature`.
* **Integración Continua:** Configuración de un Linter automático para archivos Markdown.
* **Estándares de Documentación:** Uso de archivos de soporte como `CONTRIBUTING` y `SECURITY`.
